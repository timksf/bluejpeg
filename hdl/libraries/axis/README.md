# AXI Stream library

AXI4-Stream fabric types (`AxiStream`) and a dual-clock AXI4-Stream FIFO
(`AxiStreamAsyncFifo`) built on the Bluespec `mkSyncFIFO` synchronizer.

Vendored unchanged from `parlio-fpga/src/axis` (as used by bluerf), commit
`aff9fd8`. That repository is not public, so the sources are kept here instead
of a submodule. Update both files together when pulling a newer version.
